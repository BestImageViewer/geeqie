# Bundled fallback icons

Standard symbolic SVGs are copies from the GNOME Project's
[Adwaita icon theme](https://gitlab.gnome.org/GNOME/adwaita-icon-theme),
installed package version 50.0-1.
Only license comments were added; the artwork is unchanged.
Attribution: [GNOME Project](https://www.gnome.org/).

Adwaita licensing and attribution are retained in `COPYING.Adwaita`.
The pan-up and pan-down icons carry CC-BY-SA-4.0 notices; its full text
is retained in `COPYING.Adwaita`. For other imported icons,
the LGPLv3 license option is accompanied by `COPYING.LGPL-3` and
`COPYING.GPL-3`. Original SVG source is included here.

The following SVGs are original Geeqie artwork, licensed GPL-2.0-or-later:

- `edit-delete-shred-symbolic.svg`
- `emblem-readonly-symbolic.svg`
- `emblem-symbolic-link-symbolic.svg`
- `emblem-unreadable-symbolic.svg`
- `preview-file-symbolic.svg`

The PDF fallback reuses `../gq-icon-pdf.svg`.
Resource aliases use a `gq-fallback-` prefix to keep system theme icons first
in lookup order. Preserve the `-symbolic` suffix for GTK recoloring.
